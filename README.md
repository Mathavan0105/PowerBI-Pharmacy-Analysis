# Power BI Pharmacy Analysis Dashboard

## 📌 Project Overview
This project presents an interactive **Power BI Pharmacy Analysis Dashboard** designed to analyze pharmacy sales performance, inventory status, expiry risk, and profitability.  
The dashboard helps stakeholders make **data-driven decisions** related to stock management, revenue growth, and loss prevention.
---

## 🎯 Business Objectives
- Monitor medicine-wise and category-wise sales
- Identify fast-moving and slow-moving drugs
- Track near-expiry and expired medicines
- Analyze revenue, profit, and demand trends
- Improve inventory planning and reduce wastage

---

## 🛠 Tools & Technologies
- **Power BI Desktop (PBIP format)**
- **DAX (Data Analysis Expressions)**
- **Excel / SQL (Data Source)**
- **Git & GitHub (Version Control)**
